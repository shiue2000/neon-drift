# Neon Drift

A neon survival arcade game built with HTML, CSS, and JavaScript.

[Play Neon Drift](https://neon-drift-arcade-1027.as7875078750.chatgpt.site/)

## Play locally

Open `index.html` in a modern browser. No installation or build step is required. Fonts load from Google Fonts, with local fallback fonts available.

## Controls

- Move with WASD, arrow keys, or the pointer.
- Press Space or click DASH to dash through enemies.
- Press P or Escape to pause.
- Collect cyan shards for 100 points each.
- Avoid coral hunters. One hit ends the run unless you are dashing.

Personal best scores are saved in the browser on the current device.

## Source

`index.html` contains the page layout, styling, canvas rendering, and game logic. The game has no server or package dependencies.
